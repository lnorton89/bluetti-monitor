# Quick Task 20260519-181606: Standalone Analytics App

## Goal

Create a standalone `analytics/` React + TypeScript app with its own `package.json`, using the existing Bluetti API data model for live status, historical telemetry, and derived analytics.

## Plan

1. Scaffold the analytics package
   - Add Vite, React 19, TypeScript, TanStack Query, TanStack Router, Recharts, uPlot, Tailwind 4, date-fns, and lucide-react.
   - Keep all source files inside `analytics/`.

2. Build telemetry data access and analytics transforms
   - Add typed API helpers for `/devices`, `/status`, `/fields/{device}`, `/history/{device}`, and `/ws`.
   - Resolve available AC500 fields into stable analytics metrics.
   - Bucket historical readings and derive power balance, source share, battery movement, and field comparison series.

3. Build and verify the user-facing analytics page
   - Implement responsive controls, KPI tiles, power/battery charts, health/source panels, and arbitrary field comparison.
   - Support mock mode for UI development without hardware.
   - Run TypeScript/build verification.
