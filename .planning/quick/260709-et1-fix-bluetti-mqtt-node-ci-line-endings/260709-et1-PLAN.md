# Fix bluetti-mqtt-node CI Line Endings

## Goal

Fix the submodule GitHub Actions `validate` failure caused by Windows checkout converting source files to CRLF before Biome lint runs.

## Plan

1. Add a submodule `.gitattributes` that keeps source, test, config, workflow, and docs files checked out with LF line endings.
2. Mark generated/binary package artifacts as binary.
3. Verify Git attributes apply to representative files.
4. Run `npm --workspaces=false run validate` locally.
5. Commit and push the submodule, then update and push the parent submodule pointer.
