# Plan: Analytics Feature Planning (260529-m8c)

**Description:** Scope three new analytics features: time-period comparison, chart annotations/notes, and export/save reports.

**Action:** Research the current codebase and write a feature specification covering all three features:

### Feature A: Time-Period Comparison
- **What:** Overlay current period's data with a previous period (yesterday, last week, same day last week) on Power Balance, Solar Input, and Battery Posture charts.
- **Key decisions:**
  1. UI: Add a "Compare with" dropdown next to the range selector (options: None, Yesterday, Same day last week, Same range last week)
  2. Data: Fetch two parallel history queries — primary range + comparison range. Bucketing must align (same bucketMs, offset by the comparison delta).
  3. Rendering: DenseTimeSeries already supports multiple series lines. Add a visual style for comparison lines (dashed, lower opacity, distinct from primary palette). Legend entries indicate "Yesterday" or "Last week".
  4. Impact on timeline loading: Parallel queries increase load. Use stale-while-revalidate; comparison data can be cached and shown slightly delayed.

### Feature B: Chart Annotations / Notes
- **What:** Allow adding text notes pinned to specific timestamps on any chart. Notes persist in localStorage (simple) or sync to the API (advanced).
- **Key decisions:**
  1. Storage: Start with localStorage only — keyed by `analytics-annotations-{device}` with shape `{ts: number, text: string, color?: string}[]`.
  2. UI: Click on a chart point → inline popover to add/edit note. Existing notes shown as small markers (dots, flags) on the chart. A notes panel lists all notes for the visible period.
  3. Rendering: uPlot supports plugin hooks — add a custom plugin to draw annotation markers on the chart canvas. Markers are small colored circles at the annotation's timestamp.
  4. Export: Annotations are included in export metadata if exporting.

### Feature C: Export / Save Reports
- **What:** Export current analytics view as CSV (raw data), PNG (chart screenshot), or PDF (full report page).
- **Key decisions:**
  1. CSV: Derive from the bucketed timeline data — one row per bucket, columns for each series value. Add an "Export CSV" button in the controls band.
  2. PNG: Use `html-to-image` (or `dom-to-image-more`) to capture individual chart elements as PNG. Add per-chart export buttons.
  3. PDF: Use a print-friendly CSS stylesheet via `@media print` + the browser's native print dialog. Add a "Print report" button that triggers `window.print()`.
  4. Cost: `html-to-image` is lightweight and already common in React charting apps. No paid service needed.

### Implementation Priority
1. **Time-period comparison** — highest value for understanding trends, builds on existing DenseTimeSeries infrastructure
2. **Export CSV/PNG** — medium effort, high practical value for sharing/archiving
3. **Chart annotations** — lowest effort per feature, but nice UX touch that ties into export
