# Plan: Analytics Time-Period Comparison (260529-p8q)

**Description:** Implement a "Compare with" feature that overlays yesterday's or last week's data as dashed comparison lines on Power Balance, Solar Input, and Battery Posture charts.

## Architecture

- **No API changes** — uses existing `/history/{device}` endpoint with an offset `since` parameter
- **Two parallel queries** — primary and comparison, same bucketing, same fields
- **DenseTimeSeries** gets a new optional `comparisonSeries` prop for rendering dashed comparison lines
