# Implement Optional MQTT TLS Support In bluetti-mqtt-node

## Goal

Add optional MQTT TLS support without changing existing plain MQTT behavior.

## Plan

1. Extend MQTT bridge options with optional TLS settings passed through to mqtt.js.
2. Add CLI/config support for CA, client certificate, client key, servername, and insecure/self-signed mode.
3. Update example config safely.
4. Add regression coverage for connector TLS options and CLI TLS config validation/file loading.
5. Verify with lint and coverage.
