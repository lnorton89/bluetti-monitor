# Summary

Implemented optional MQTT TLS support in `lib/bluetti-mqtt-node`.

## Changes

- Added `tls` to `BluettiMqttClientOptions`, passed through to mqtt.js as `ca`, `cert`, `key`, `rejectUnauthorized`, and `servername`.
- Added CLI flags:
  - `--mqtt-ca <path>`
  - `--mqtt-cert <path>`
  - `--mqtt-key <path>`
  - `--mqtt-servername <name>`
  - `--mqtt-insecure`
- Added JSON config support under `tls` with `caPath`, `certPath`, `keyPath`, `rejectUnauthorized`, and `servername`.
- Updated `config.example.json` with a safe TLS example.
- Added regression tests for MQTT connector TLS option forwarding and CLI TLS config validation/file reads.
